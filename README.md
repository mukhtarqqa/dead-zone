# Dead Zone — запуск и кооператив

Готовая Windows-сборка игры **Dead Zone** (Unity, кооперативный режим через интернет и LAN).

## Быстрый запуск
1. Скачайте проект или клонируйте репозиторий:
   ```bash
   git clone https://github.com/mukhtarqqa/dead-zone.git
   ```
2. Запустите `DeadZone.exe`.
   > **Важно:** все файлы рядом с `DeadZone.exe` и папка `DeadZone_Data` должны оставаться вместе в одной папке.

3. Выберите персонажа мышью или клавишами **1–3**.
   - **«Начать вылазку»** — одиночная игра.
   - **«Кооператив»** — экран сетевой комнаты.

---

## Кооператив по интернету
1. Каждый игрок выбирает своего героя до подключения.
2. Хост нажимает **«Кооператив» → «Создать комнату»** в разделе «Через интернет».
3. Хост передаёт друзьям полученный код комнаты.
4. Друзья вводят код и нажимают **«Войти по коду»**.
5. Когда команда собралась, хост нажимает **«Начать матч»**.

*Проект привязан к Unity Cloud. Личные Unity-аккаунты игроков не требуются — вход анонимный.*

---

## В локальной сети (LAN)
1. Хост нажимает **«Создать LAN»**.
2. Подключающиеся вводят IPv4-адрес компьютера хоста и нажимают **«Подключиться»**.
3. Используется UDP-порт `7777`. `127.0.0.1` подходит для тестирования нескольких окон на одном ПК.

---

## Правила команды
- Доступно три уникальных героя (до 3 игроков одновременно).
- Два участника не могут выбрать одного и того же героя.
- Подключение новых участников происходит до старта матча.
- При выходе хоста сессия завершается.
- `Esc` в одиночной игре ставит паузу; в кооперативе открывает меню комнаты без остановки боя.
- У каждого игрока свой персональный выпавший лут.

---

## Управление
- **WASD** — движение
- **Мышь** — прицеливание
- **ЛКМ** — стрельба
- **R** — перезарядка
- **Tab** — смена оружия
- **Shift** — рывок
- **Q** — активная способность
- **E** — подбор предмета
- **Удержание E (2 сек)** — воскрешение раненого союзника
- **G** — граната
- **F** — мина

---

## Оружие
У старта возле каждого игрока лежат АК-47, пулемёт и дробовик. Подойдите к оружию и нажмите **E** для подбора. Пистолет имеет бесконечный боезапас; остальное оружие требует патронов из зелёных ящиков припасов.
