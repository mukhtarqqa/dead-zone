# Dead Zone — запуск и кооператив

## Запуск
Открой Builds/DeadZone.exe. Все файлы рядом с EXE и папку DeadZone_Data нужно сохранять вместе. Это ранняя Windows-сборка, не финальная версия игры.

Выбери персонажа мышью или клавишами 1–3. «Начать вылазку» запускает одиночную игру. «Кооператив» открывает экран комнаты.

## По интернету
1. Каждый игрок выбирает своего героя до подключения.
2. Хост нажимает «Кооператив» → «Создать комнату» в разделе «Через интернет».
3. Хост передаёт друзьям отображаемый код.
4. Друзья вводят код и нажимают «Войти по коду».
5. Когда команда собралась, хост нажимает «Начать матч».

Проект уже привязан к Unity Cloud. Для интернет-комнат требуется соединение с сервисами Unity. Личные Unity-аккаунты игроков для входа в игру не нужны: используется анонимный вход игрового клиента.

## В локальной сети
Хост нажимает «Создать LAN». Друзья вводят IPv4-адрес компьютера хоста и нажимают «Подключиться». 127.0.0.1 подходит только для проверки нескольких экземпляров на одном компьютере. Используется UDP-порт 7777.

## Правила команды
- Пока доступны три уникальных героя, одновременно могут играть трое. Сетевой код рассчитан максимум на четверых; для четвёртого места нужно добавить четвёртого героя в HeroCatalog.
- Два участника не могут занять одного героя.
- Новые участники подключаются до начала матча.
- Для возвращения после разрыва связи нужно использовать тот же профиль игры и прежнего героя. Отключившийся персонаж выбывает; после возвращения ждёт следующей волны.
- При выходе хоста матч завершается. Переноса хоста нет.
- Esc в одиночной игре останавливает время; в кооперативе открывает экран комнаты без остановки боя.
- У каждого игрока свой выпавший лут.

## Управление
WASD — движение; мышь — прицел; ЛКМ — стрельба; R — перезарядка; Tab — смена оружия; Shift — рывок; Q — активная способность; E — подбор; удержание E около раненого союзника в течение двух секунд — поднятие; G — граната; F — мина.

## Оружие
У старта рядом с каждым игроком лежат его личные АК-47, пулемёт и дробовик. Подойди к оружию: название ближайшего предмета появится в HUD. Нажми E для подбора. Первый ствол займёт свободный слот, следующий заменит оружие в руках. Пистолет тоже можно заменить; старый ствол останется на земле с прежними патронами.

Пистолет имеет бесконечный запас, остальные стволы требуют патронов. Зелёные припасы пополняют запас носимого оружия и дают гранату. При попытке выстрелить с пустым магазином автоматически начинается перезарядка, если есть запас. Дробовик эффективен вблизи, АК точнее пулемёта, пулемёт имеет большой магазин и долгую перезарядку.

## Ограничения этой сборки
Это первая версия сетевой игры. Полное прохождение и баланс на реальной команде ещё требуют проверки. Анимации временные и только фронтальные. Звуки, казахский перевод, постоянная статистика, продвинутая навигация и финальные атаки боссов ещё не завершены.
