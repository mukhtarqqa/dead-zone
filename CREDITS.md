# Материалы

Городская арена, процедурные фасады, машины, деревья, оружие и эффекты создаются кодом проекта. Растровые материалы и спрайты в Resources подготовлены с помощью генерации изображений; доступны для редактирования в проекте. Промпт карты: [Docs/ART_PROMPTS.md](Docs/ART_PROMPTS.md).

Персонажи вдохновлены Re:Zero и Jujutsu Kaisen. Права на оригинальных персонажей принадлежат соответствующим правообладателям.

Лицензии TextMesh Pro находятся в Assets/TextMesh Pro. Unity-пакеты устанавливаются через Package Manager, условия находятся в соответствующих пакетах.

Исходные сторонние карты Cainos/LoBit City не распространяются. Старая карта сохранена только в локальной резервной копии рабочего проекта.
