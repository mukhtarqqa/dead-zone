# Выстрел AK-47

Одобренные пользователем `ak47_01.wav`, `ak47_02.wav`, `ak47_04.wav` извлечены из установленной Counter-Strike 2, build 26281801, инструментом Source 2 Viewer CLI 20.1. Правообладатель записей — Valve Corporation.

Файлы для редактирования: `Assets/Resources/Audio/Weapons/AK47`. Это отдельные выстрелы; очередь воспроизводится по фактическим выстрелам оружия с существующим интервалом 0.115 секунды. На каждый выстрел выбирается одна из трёх записей, соседние одинаковые варианты исключены. Тон и скорость оригинальные, stereo 44100 Hz PCM, громкость — 0.82 от общей громкости эффектов. При стандартной громкости 0.5 уровень соответствует одобренному образцу.

Воспроизведение: `ZoneFeedback.PlayShot`, включая уже существующие вызовы у сетевых персонажей. Импорт: меню `Dead Zone/Audio/Prepare approved AK47 shots`. Исходные SHA-256 и сведения об извлечении: `Assets/DeadZone/Audio/AK47/PROVENANCE.json`.

Проверено в Unity 6000.6.0f1: импорт трёх stereo PCM записей, очередь из шести выстрелов с фактическим звуковым сигналом, исходный тон, отсутствие одинаковых соседних вариантов и продвижение кадров/DSP (`DZ_AK47_AUDIO_IMPORT_PASS`, `DZ_AK47_AUDIO_PLAYBACK_PASS`). SHA-256 всех WAV совпадают с исходным экспортом. В текущей консоли после проверки — 0 ошибок. Отдельная сетевая сессия на нескольких компьютерах в этой работе не запускалась.
