# Перезарядка AK-47

Одобренный WAV: `Assets/Resources/Audio/Weapons/AK47/ak47_reload.wav`, длительность **1.8 секунды**. Время перезарядки и баланс оружия сохранены.

Это последовательность из записей Valve, взятых из установленной CS2: `Weapon_AK47.Clipout` → `ak47_clipout_01.wav` на 0.10 с; `Weapon_AK47.Clipin` → `magazine_slide_01.mp3` на 1.02 с с относительной громкостью 0.3; `Weapon_AK47.BoltPull` → `ak47_boltpull_01.wav` на 1.41 с. Исходные тон и скорость сохранены; паузы адаптированы к Dead Zone. Оригиналы и границы сборки: `Assets/DeadZone/Audio/AK47Reload`.

`ZoneWeaponReloadAudio` создаёт отдельный AudioSource у каждого игрока. Звук начинается один раз на перезарядку, синхронизируется с уже прошедшей частью при позднем получении состояния, прекращается при отмене, смене оружия, гибели, падении, отключении персонажа и выходе из матча. Одиночная пауза приостанавливает звук. Общая громкость эффектов применяется с множителем 0.9. Позиция магазина в анимации AK-47 согласована со временем извлечения и установки. Сетевой протокол не меняется.

Импорт через Unity: `Dead Zone/Audio/Prepare approved AK47 reload`.

Проверено в Unity 6000.6.0f1: `DZ_AK47_RELOAD_IMPORT_PASS`, `DZ_AK47_RELOAD_PLAYBACK_PASS`. Воспроизведение продвигается; два персонажа используют независимые источники; повтор состояния не перезапускает запись; проверены отмена при смене оружия, падении и гибели, вход в середину перезарядки, завершение, пауза и продолжение. В текущей консоли — 0 ошибок. WAV побайтово совпадает с одобренным образцом. Проверка двух персонажей выполнена локально; отдельная сессия на нескольких компьютерах в этой работе не запускалась.
